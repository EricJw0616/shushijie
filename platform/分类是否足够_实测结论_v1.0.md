> **② 除了这九类，还有没有别的类型；前面测试里出错的地方，现在是什么状况。**

## 一、四月天文学卷：它不是散文集

### 1.1 书里自己写着六种文体

这本书有明确的分卷标题（OCR 后拆成「散\n \n文」这种形式），程序按标题切出实测构成：

| 文体 | 汉字数 | 占比 |
|---|---:|---:|
| 小说 | 41,456 | **40%** |
| 剧本 | 27,284 | **26%** |
| 散文 | 20,309 | 20% |
| 评论 | 5,931 | 6% |
| 诗歌 | 5,785 | 6% |
| 译文 | 3,053 | 3% |
| **合计** | **103,818** | 100% |

**散文只占两成，小说与剧本合起来 66%。把整本叫「散文集」是把六成内容说错了。**

### 1.2 为什么之前判成 P6

整本的特征是 `第一人称 19.9 对白 9.9%`，命中 P6 的「第一人称高 + 有对白」分支。
这是全书的**平均**特征——散文段的「我」把小说段和剧本段的第三人称稀释掉了。
平均值把一个混合体伪装成了单一文体，这是六轴测量在这种书上的固有盲区。

### 1.3 现在的处理

不强行归一类，改为**报构成**：

```
整本主判 P6（低置信），稳定性 55%，分块吻合 40%
合集：6 种文体，占比最大为小说 40%
```

页面/档案上应该这么写：

> 本书为多文体合集：小说 40%、剧本 26%、散文 20%、评论 6%、诗歌 6%、译文 3%。
> 主判「散文型」仅覆盖两成内容，不代表全书。

**代码改动**：`measure.py` 新增 `sections()`，只认书上自己写的分卷标题，不猜。
22 本全扫一遍，只有这本书命中，零误报。

## 二、九类分类到底够不够

### 2.1 先说一件必须先说的事：12 个测试样例，8 个不合格

上一版报告说「11 个样例 7 个判错」，这个结论有一半站不住。原因是把
**「素材不能用」误读成「系统不认识这个类型」**。这两件事完全不同。

| 样例 | 状态 | 真正的问题 |
|---|---|---|
| 法规_刑法 | **合格** | 判 P1 规范型，置信高，吻合 90% ✅ |
| 法规_宪法 | **合格** | 判 P1 规范型，置信高，吻合 90% ✅ |
| 法规_行政处罚法 | **合格** | 判 P1 规范型，置信高（仅 9,046 字，10 块每块约 1,055 字，低于 1,500 的分块下限，无投票）✅ |
| 教材_化学高中 | **合格** | 判 P2 知识型，置信中，吻合 **100%** ✅ |
| 教材_物理高中 | 不合格 | **句均长 1784 字/句**，PDF/LaTeX 抽丢了全部句末标点 |
| 教辅_物理习题集 | 不合格 | 句均长 671 字/句，同上 |
| 工具书_汉字字典 | 不合格 | **行中位长 3 字**，一行一个字头，文本最小单位不是句 |
| 教材_语文七年级上册 | 不合格 | 5,492 字，不足 8,000 |
| 教材_数学 | 不合格 | 3,039 字 |
| 年鉴_统计公报2023 | 不合格 | 3,407 字 |
| 生活_菜谱 | 不合格 | 3,853 字 |
| 外文_傲慢与偏见 | 不合格 | 0 汉字（纯英文） |

**合格 4 / 12**。这 4 个的判型全部正确，没有一个是错的。

**这意味着：「九类不够用」这个判断，目前没有证据支持，也没有证据否定。**
前面那些看起来像「判错」的案例，绝大多数是素材烂，不是类型新。

### 2.2 真正能说的结论：九类里有 5 类只有 1 本书支撑

22 本书按原型分类后的支撑情况：

| 原型 | 支撑书数 | 状态 |
|---|---:|---|
| P1 规范型 | 0 | **零样本。判据从未在真实书上验证过**（只在测试集法规上跑通） |
| P2 知识型 | 1 | ⚠ 只有《四月天·建筑卷》 |
| P3 论说型 | 1 | ⚠ 只有《闲情偶寄》 |
| P4 叙事型 | 10 | 稳固 |
| P5 戏曲型 | 1 | ⚠ 只有《牡丹亭》 |
| P6 散文型 | 5 | 稳固 |
| P7 韵文集型 | 2 | 一般 |
| P8 条目型 | 1 | ⚠ 只有《山海经》 |
| P9 选集笺注型 | 1 | ⚠ 只有《古文观止》 |

**支撑 1 本的意思是：这条判据是照着那一本书写的，换一本书未必成立。**
比如 P5 的判据是「出/折 ≥8 或（曲牌 ≥50 且科介 ≥20）」，《牡丹亭》能过，
但一本没有「第X出」标记的京剧剧本、或曲牌标记用另一种写法的传奇，就会掉出去。

**P1 更严重：书库里一本都没有，判据完全没在真实书上验过。**
测试集里三本法规能判对，但那三本是干净的法条文本，不是「书」。

## 三、这次修掉的六个真实 bug

不是"优化"，是原来就算错的。

### bug 1：分块投票全部失效，混合检测等于不存在

`chunk_votes()` 直接调 `judge()`，而 `judge()` 内含 `gate()`。
`gate()` 的 `MIN_HAN=8000` 是按**整本书**定的，切成 10 块后每块只有几千字，
于是每块都被判「样本不足」。22 本的分块投票**全部是 `[None, None, ...]`**。

后果：《四月天·文学卷》40% 是小说，系统却报告「无混入」。
现在新增 `gate_chunk()`（只查汉字率与句读，不查体量），分块投票恢复正常。

### bug 2：格式轴是绝对计数，分块后永远不达标

`chu / qupai / kejie / tiao / ping / tm` 数的是「出现几次」，与书有多长直接相关。
《牡丹亭》整本 出=110、曲牌=478、科介=857，切 10 块后每块只有 出=2~7，
6/10 块被判「什么都判不出」——**不是书不统一，是阈值没折算**。

现在 `chunk_thr()` 按体量比例折算阈值。但加了硬约束：

> **某个轴只有在整本层面已经成立时，才允许在分块里折算使用。**
> 整本不成立 → 该轴在分块里禁用（阈值设 inf）。

这条约束是踩出来的：《元曲三百首》整本 qupai=0，折算后阈值降到 5，
某个块凑出 5 个 `【】` 就被判成 P5 戏曲型——**凭空造出混入**。
放宽一步后又出现「整本 chu=3 < 8 不成立，但切块后阈值降到 1，一块里 1 个『第X出』就判 P5」
——**把噪声放大成证据**。两次都修掉了。

### bug 3：汉字率分母算错，字典被判「非中文」

旧口径分母是「全部非空白字符」，把拼音、注音符号、数字、标点都算进分母。
《康熙字典》式文本每字带拼音和注音，旧口径 52.7% → 判「非中文文本」。

新口径分母只算有文字属性的字符（汉字+拉丁+假名+谚文）：字典 75.9%、年鉴 100%。
**这两本都是中文，旧口径把它们赶出去了。**

### bug 4：字典被判「韵文集·高置信」

汉字率修好后，字典暴露了更严重的问题：**它被判成 P7 韵文集，置信「高」，稳定性 100%**。

原因：字典一行一个字头或一个义项，句末标点稀少且分布随机。
于是 `smed=5`、`Q=2.4`、`p3=0.7`、`R=0.8` **四个条件同时成立**，恰好命中 P7 的全部判据。

**这是高置信的错判，比拒判危险得多。** 现在加版式门：
`行中位长 ≤8 且句中位 ≤8` → 拒判，理由是「文本最小单位是字/词而非句」。
22 本书最低行中位长 13（《古文观止》），不会被误拦。

### bug 5：混入的判据要求「主判自己先不稳」

旧逻辑：`主判占比 < 80% 且 混入块 ≥ 2` 才报混入。
这等于说：**只有主判自己站不住的时候，才肯承认书里有别的东西。**
一本 80% 散文 + 20% 小说的集子，永远报不出混入。

现在改为：只要有一块判成互斥类就报，并新增 `吻合度`（主判在分块中的占比）。
吻合度是比 mixed 更硬的一条证据——只有 40% 的块支持主判，「整本属于这一类」这话就不该说。

### bug 6：《四月天·文学卷》40% 是小说但报告「无混入」

这是 bug 1 + bug 5 的共同后果。修复后，`INCOMPAT['P6']` 不含 `'P4'`（旧表认为散文与叙事不互斥），
所以小说部分体现在 `吻合度 40%` 而非 `mixed` 里 —— **这个表达是对的**：
合集内部的不同文体不算「混入异物」，它是书本身的结构，用 `anthology` 字段单独表达。

## 五、还差什么（未解决，如实列出）

### 5.1 要回答「九类够不够」，必须先补合格样例

每类至少一本 **≥8000 汉字、句读完好、不是词条排版** 的真实书。
现在缺的是：

| 类型 | 缺什么 | 为什么难 |
|---|---|---|
| 教材/教辅 | 干净文本的教材（唯一合格的化学教材只能证明「教材→P2」这一条） | 网上流传的教材多是 PDF 转换，句读全丢 |
| 工具书 | 词典、百科、手册、索引 | 全都是一行一条，天然触发词条排版门 |
| 年鉴 | 任意一本（现有 3,407 字） | 表格占 34%，六轴测不到表格 |
| 期刊 | 学术/大众/报纸三种形态 | 完全没样本 |
| 图鉴 | 植物志、器物图录、地图集 | 图像层完全未覆盖 |

**本机网络受限**：维基文库、GitHub raw 均不可达，只有 Project Gutenberg 能通。
补齐样本需要能访问的中文公开语料源，这件事卡在取数上，不是卡在判据上。

### 5.2 表格与图像是结构性缺口，不是缺样本能解决的

年鉴（表格 34%）、图鉴（图版层）、教辅（习题 18.6/千字）这三类，
**六轴里一个轴都没有测**。就算给了合格样本，现有产物清单也接不住：
年鉴的价值在表格数据，而 `ARCH` 里没有任何一项能承载表格。

要覆盖它们，得先加轴（表格行率、图版密度、习题密度已在 `typetest.py` 里测了、但没进判型），
再定产物。这是「开新原型」，不是「调阈值」。

### 5.3 单片支撑的五个类需要交叉验证

P2/P3/P5/P8/P9 各只有 1 本书。判据是否成立，**只有换一本同类书才知道**。
建议优先验 P5（戏曲）：只要找一本曲牌标记写法不同的剧本就能证伪或证成。

## 六、一句话总结

**四月天文学卷不是散文集，是六种文体的合集，散文只占两成——这个结论有书上自己的分卷标题作证，可复算。**

**九类分类够不够，今天答不了。** 12 个测试样例只有 4 个够格，4 个全对；
说「不够」的旧结论建立在 8 个不合格素材上。要给出准确答复，
需要先补齐合格样本——这卡在取数，不卡在判据。
