## 一、为什么改

上一轮用 12 个真实样例做了类型覆盖测试，暴露三个必须修的缺陷：

| 缺陷 | 实证 | 后果 |
|---|---|---|
| 判型没有拒绝出口 | `judge()` 末行无条件 `return 'P6', ...`，喂「阿巴阿巴测试测试」也判成 P7 韵文集型、置信中 | 「覆盖率 100%」是兜底分支必返回造成的假象，遇到新类型不报警 |
| 空值当成零值 | `lens = [...] or [1]`，汉字数 0 时 `smed=1`，四个 `<` 条件全因「没数据」成立 | 纯英文书《傲慢与偏见》被判成中文韵文集型 |
| 置信是硬编码字符串 | `return 'P4', [...], '高'`，17 个分支各写死一档 | 衡量的是「这条规则的阈值有多严」，不是「这本书有多可靠」 |

## 二、改了什么

### 1. 新增判型前的数据质量门 `gate()`

```
MIN_HAN = 8000        汉字数下限（真实书最小 51540）
MIN_HAN_RATIO = 60.0  汉字占非空白字符比（22 本最低 74.5%）
MAX_SAVG = 150.0      句均长上限（22 本最高 32.0）
```

阈值全部由 22 本实测下界倒推，不凭感觉定。

**关键设计：拒判分两类，混淆会把结论读反**

| kind | 含义 | 正确动作 |
|---|---|---|
| `data` | 文本本身不可用（太短／非中文／丢标点） | 补数据重试，**不算遇到新类型** |
| `unknown` | 数据可用，但九类主动特征全不成立 | 疑似第十类，需人工判断 |

### 2. `judge()` 去掉兜底分支

末行从「无条件塞进 P6」改为返回 `None` + 拒判原因 + `kind='unknown'`。

### 3. 置信度改为实测抗扰动率

把 `judge` 的全部 28 个数值阈值参数化，随机浮动 ±20% 后重判，重复 300 次，
「判型不变」的比例就是稳定性。种子绑实测特征值，保证重跑得同一个数。

```
≥0.995 → 高     ≥0.90 → 中     <0.90 → 低
```

**参数都是验证过的，不是拍的**：

- 扰动幅度 ±20%：±10%~±15% 排名一致性 rho=+0.81，放大到 ±25% 掉到 +0.47，说明 ±20% 已接近本测量分辨率上限
- 采样 300 次：n=100 与 n=1000 结果差不到 5 个百分点
- 耗时：单本约 1 毫秒，22 本合计 3 秒（含扫描与卡片投票）

### 4. 新增两条测量轴

| 轴 | 定义 | 用途 |
|---|---|---|
| `term` 术语密度 | 每千字「是/即/由于/因此/包含/分为…」次数 | **已参与判型**：P2 句长分支必要条件 `term>=5` |
| `tbl` 表格行率 | 含 2 个以上 `\|` 的行占比 | 仅测量，供开新原型时判断 |
| `ex` 习题密度 | 每千字「练习/习题/例题/证明…」次数 | 仅测量 |

`term` 轴是这轮唯一新增的判型条件，原因见下。

## 三、验证结果

### 22 本已知书：判型零变动

连跑两次 md5 一致（`1e9daadf4feec844b6edabee4d18cd02`）。

**置信度重算前后对比**

| | 旧（硬编码） | 新（实测） |
|---|---|---|
| 高 | 14 | **16** |
| 中 | 8 | **4** |
| 低 | 0 | **2** |

四本变动，每一本都有数据支撑：

- 《元曲三百首》《背影2019版》中 → **高**：旧标签低估了。两者各条件离阈值都远，扰动 300 次判型 100% 不变
- 《四月天·文学卷》中 → **低**：稳定性仅 **55%**。`Q=9.9` 距 P4 门槛 `Q>=10` 只差 0.1，而 `p3=18` 远超 12，阈值略降就切到 P4
- 《四月天·建筑卷》中 → **低**：稳定性 **89%**，贴着 0.90 分界

### 12 个测试样例：拒判 8 个，正判 4 个

| 样例 | 结果 | 性质 |
|---|---|---|
| 外文_傲慢与偏见 | 拒判 | data（汉字 0） |
| 工具书_汉字字典 | 拒判 | data（汉字率 52.7%<60%） |
| 教材_物理高中 | 拒判 | data（句均长 1784 字，LaTeX 丢标点） |
| 教辅_物理习题集 | 拒判 | data（句均长 671 字） |

## 四、一个必须记下来的判型漏洞

### 清单型文本会被判成 P2 知识型

构造一段 36000 字的参数清单（`产品编号X，规格A型，重量十二公斤…`），
汉字量、汉字率、句读全部合格，结果：

```
savg=30.0 → 命中 P2「句均长≥28 且 对白<8 且 第三人称<6」→ P2 知识型，稳定性 71%
```

**根因**：清单的句均长天然落在 28~45，与说明文完全重叠。光看句长必然混淆。

**解法**：加必要条件 `term >= 5`。实测：

| 文本 | term |
|---|---|
| 参数清单 | **0.0** |
| 法规（刑法/宪法/行政处罚法） | 6.7 / 7.2 / 10.9 |
| 教材（化学/物理/习题） | 19.9 / 24.5 / 27.6 |
| 22 本文学书（走 savg 分支的） | 19.6 ~ 33.4 |

分界清晰，取 5 留足余量。加上后清单型正确落入 `unknown` 拒判，22 本判型零变动。

## 五、这轮**没有**解决的事

### 1. 测试集不合格，覆盖问题仍未验证

12 个样例里 8 个因素材太短或抽取质量差被拒判。**这意味着上一轮「11 个样例 7 个判错」
的结论现在部分失效**——那些「判错」里有一半其实是素材不可用，不是类型判断错误。

要真正回答「九类够不够」，需要每类样本 ≥8000 汉字且句读完好。当前只有法规三门合格。

### 2. `stability` 只衡量「稳不稳」，不衡量「对不对」

公式衡量的是判型对阈值是否敏感。规则本身漏了特征（比如散文与日记、随笔全部重叠），
那算出来的高稳定性也只是「稳定地错」。

**必须抽验才能对外承诺**：22 本里标「高」的 16 本，是否都人工看过判型结果？

### 3. 表格、图像两类仍是零测量

`tbl` 轴只测了表格行率，没有测量表格内容结构。图像完全没有轴。
《中国东北药用植物彩色图志》这类书进来仍会被静默处理掉最核心的价值。

### 4. P1 规范型仍只有 3 个样本

虽然判对了，但 3 个样本都是法规，同源。政府部门规章、行业标准、企业制度
是否同样落进 P1，未验证。
