## 原型五步验证
1. 点「五事」→ 右侧看定义、要点、原文；
2. 点「五事 → 七计」的边 → 看关系类型与证据锚点；
3. 双击「五事」→ 邻域视图；
4. 关掉「篇章归属」图层 / 点「按篇聚焦」；
5. 右上「图谱质检」。

## 重建
```bash
python3 build_kg.py   # 读 ../distill 的资产，生成 kg_data.json
python3 build.py      # 模板 + 数据 → 知识图谱_原型_孙子兵法.html
```
`_proto_template.html` 是原型源码，`__KG_DATA__` 为数据占位符。
