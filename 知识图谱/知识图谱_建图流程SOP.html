新书进图谱：一条流程、
一个“没建过”的简单办法、一套复用规则

客户不做建图决策。系统判断这本书能出什么图，内部按模板建；建好自动出现。这份 SOP 只回答三件事：新书怎么进来、第一次遇到新书型怎么办、怎样不变成“一书一建”。

01

新书 → 图谱：主流程

New book → graph

解析完成不是终点。系统在入库后追加一个「建图作业」，自动判型、选模板、抽边、质检，通过才发布。客户只在发布之后看到图，中间不出现任何“要不要建”的问题。

FIG 01

六步主流程：三处闸门，客户只见最后一步

自动为主
关键：「解析完成」之后追加的不是一个页面动作，而是一个内部作业。作业失败不影响客户；成功才写文件、才出现在下拉里。

02

没构建过的书：一条简单办法

First time a type appears

第一次遇到没有模板的书，不要为它单独写一套代码。只做四步：判型 → 四选一模板 → 一份配置 + 20 条边试跑 → 发布或只出索引。只有四个模板都不像时，才新增模板。

FIG 02

新书型：四条路，只有一个出口需要新代码

内部流程，客户无感
「20 条边」是内部试跑：不是只建 20 条就上线，而是拿 20 条关系验证「这本书能不能每条都指到原文」。能，才批量；不能，就只出索引，客户侧看不到失败。
1
系统
判型用现有 P1–P12 判型结果，不再人工重判。
2
系统
四选一图鉴 / 纪事 / 叙事 / 索引，选最接近，不要求完全一样。
3
编辑
一份配置 + 20 条边只写字段映射；20 条边每条能回原文。
4
系统
发布或索引通过自动发布；不通过只出索引，客户无感。
简单原则第一次遇到新书，不改内核、不写新页面、不为它单独写一套代码。能套就套，套不上才加模板；模板是“书型”的，不是“书”的。
03

如何归类、怎么复用

Classify & reuse

归类不看中图法，看「关系证据长什么样」。归类结果只决定一件事：用哪个模板、配哪些字段。新书上线时只填配置，不写代码。

四类模板，够覆盖现有书

书型怎么认节点 / 边已建 / 待建
图鉴型有科名 / 学名 / 别名 / 功效 / 主治字段科 → 属 → 种；物种 → 别名 / 功效 / 主治B56（已建）
纪事型有人物条目 + 身份 / 籍贯 / 事件，人物可核名人物 → 机构 / 地点 / 事件；人物 ↔ 人物B59（已建）
叙事型有明确人物、意象、情节，但没人物条目人物 → 地点 / 意象；人物 ↔ 人物B58（已建，人工校验）
索引型只有篇目 / 主题 / 引书，没有稳定关系主题 → 故事 / 篇目 → 人物B60 / B64 / B66 / YC（已建）

判型结果可能不完美，所以允许「最接近模板 + 配置」；不要求每本书都精准落进某一类。

复用分四级：只有最后一级才写代码

FIG 03

复用阶梯：同型书只改配置，新书型才加模板

一书一建 = 失败
判断口诀：同模板同字段 → 直接跑；同模板异字段 → 写配置；同模板多一种关系 → 模板加一个 variant；四个模板都不像 → 才新增模板。
复用级别什么时候要改什么工期
L0 直接复用同书型，字段名也一致不改，直接跑分钟级
L1 配置复用同书型，字段名不同只写一份配置0.5–1 天
L2 模板扩展同书型，多一种关系或字段模板加 variant，不动内核1 天
L3 新增模板四个模板都不像新增一个书型模板2–3 天

配置长什么样：一本书只改这一份

// app/data/kg/config/B56.json —— 图鉴型，不写代码
{
  "code": "B56",
  "template": "illustrated",
  "fields": {
    "name": "中名",       // 节点主名
    "family": "科名",     // 分类树父节点
    "aliases": ["别名", "俗名"],
    "effects": "性味功效",
    "indications": "主治用法"
  },
  "rules": {
    "dropFamilyMissing": true,
    "minEvidencePerEdge": 1
  }
}

下一本图鉴书：复制这份配置，改 code 和字段名，跑一次，出图。模板和内核都不动。

唯一例外叙事型（B58 这类）没有人物条目，关系要人工从原文抽。自动化只能出候选，必须内部确认后再发布；这个确认不给客户，也不阻塞其他书。
04

落地顺序：先让“同型书”自动，再谈全自动

Rollout
P0 · 0.5–1 天

加建图作业 + 状态

解析完成追加 kg 步骤；作业与记录里显示排队 / 建图中 / 已发布 / 跳过 / 失败；客户不出现任何中间态。

P1 · 2–3 天

内核 + 图鉴模板 + B56

把 B59 的硬编码抽成内核与模板；B56 只写配置。B56 出图后，下一本图鉴书直接复用。

P2 · 2–3 天

纪事 / 索引模板

B59 抽成纪事模板；B60 / B64 走索引或时间线；同型书只改配置。

P3 · 1–2 天

自动路由 + 发布闸门

判型命中模板自动入队；质检通过自动发布；不通过静默跳过。全程客户无感。

判断标准如果新加一本书需要改前端、改内核、或为它写一套新代码，说明归类/复用没做好；正常情况应该只写一份配置。
