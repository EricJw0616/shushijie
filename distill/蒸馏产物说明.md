生成日期：2026-10-26
源文本：`../孙子兵法_简体全文.md`（四库全书本，十三篇，6042 字，无删节）

---

## 一、这批东西是什么

不是「把书读薄」，是把书拆成机器能直接用的四种结构：

```
6042 字原文
   │
   ├─ segments.jsonl    148 条   最小语义片段，带出处锚点（检索层）
   ├─ knowledge.jsonl    60 张   概念卡：定义、要点、易混、延伸（知识层）
   ├─ rules.jsonl        55 条   规则卡：条件→动作→原理→边界（执行层）
   └─ qa.jsonl           70 对   问答对：事实/理解/应用三档（对话层）
```

四者用同一套锚点体系（`SZ-01-P09` = 始计篇第 9 段），任意一张卡都能回到原文那一句。

## 三、字段说明

### segments.jsonl（检索片段）
| 字段 | 含义 |
|---|---|
| `id` | `SZ-篇序-P段序`，如 `SZ-06-P09` |
| `篇` / `篇序` / `段序` | 定位信息 |
| `字数` | 该段汉字数 |
| `锚点` | 人读的出处，如「虚实篇 第9段」 |
| `文本` | 原文，未改一字 |

### knowledge.jsonl（知识卡）
| 字段 | 含义 |
|---|---|
| `词条` / `别称` | 概念名 |
| `原文` | 核心引文，可在正文逐字查到（`……`表示省略） |
| `锚点` / `出处` | 引文所在段落 |
| `定义` | 一句话说清是什么（整理者撰写，非译文） |
| `要点` | 3–5 条拆解 |
| `易混淆` | 常见误解或相邻概念辨析 |
| `校勘注` | 该处底本有异文时标注 |
| `延伸` | 现代场景对应（整理者加的，属解读，引用时请标明） |
| `标签` | 主题词，可用于聚合 |

### rules.jsonl（规则卡）
| 字段 | 含义 |
|---|---|
| `条件` | 触发情境 |
| `动作` | 该情境下做什么 |
| `原理` | 为什么这么做（孙子给出的理由） |
| `原文` | 规则出处原句 |
| `边界` | 不适用的情形、前提条件、可能的反噬 |
| `类别` | 示形/诱敌/时机/防守/避战/调动/消耗/分化/地形/外交/补给/脱困/决战/禁令/战术/火攻/情报/兵力/备战/决策 |

`边界` 一栏是刻意加的：孙子本人多处提醒同一手段的反面（如「围师必阙」对敌、「死地则战」对己），抽规则不留边界，用起来会出事。

### qa.jsonl（问答对）
| 字段 | 含义 |
|---|---|
| `问` / `答` | 问答正文 |
| `类型` | 事实（原文可直答）/ 理解（需解释）/ 应用（需迁移） |
| `难度` | 基础 / 进阶 |
| `锚点` / `出处` | 答案依据 |
| `注` | 版本异文提醒 |
| `关键词` | 检索标签 |

### topics.jsonl（主题卡）
这是第五层，也是唯一为「人读」而不是为机器检索设计的一层。前四层是逐段抽取（一段原文 → 一条卡），这一层是跨篇重组（多段原文 → 一张卡），差别就在这。

| 字段 | 含义 |
|---|---|
| `主题` / `副` | 主题名与一句话提示 |
| `为什么难读` | 该主题在原文里的分散状况。其中的数字由脚本实测填充，不手写 |
| `层` | 有序层次。每层含 `层`（这一层做什么）/ `句`（原文引文）/ `锚点` / `又见`（同句第二出处）/ `解`（整理者说明） |
| `对照` | 易混辨析。`甲` `甲锚` `乙` `乙锚` 都是原文，`题` 是中间标签，`辨` 是整理者说明 |
| `结论` | 收口判断，**属整理者解读，不是原文** |
| `锚点` `散布` `span` `hit_idx` | 程序生成字段：依据段去重列表、跨篇数、首尾跨度、全书段序（供条形图） |

目前 15 张分三类：

| 类 | 张数 | 例子 | 解决什么问题 |
|---|---|---|---|
| 散落型 | 3 | 死地、势、阙 | 同一主题散在多篇，读者读不到一起 |
| 易错型 | 6 | 胜可为不可为、速与久、爱兵、两个「十」、君命有所不受、诡与信 | 表面矛盾或容易读反 |
| 主干型 | 6 | 知、奇正、虚实、迂直、九变、致人 | 全书核心概念，原文层层递进或自身留缺口 |

### 2026-10-26 修订：问答引文的 14 处修正

做应用演示页时把 `qa.jsonl` 的「」引文全部拉出来比对，发现 130 处里有 17 处对不上所标锚点，分四类，已全部修正：

| 类型 | 例子 | 处理 |
|---|---|---|
| 底本用字不同 | 原文作「不可胜在**已**」，答案写成「在己」 | 照底本改回「已」，并注明通「己」 |
| 引文略去标点 | 「杀士卒三分之一而城不拔」vs 原文「杀士卒三分之一，而城不拔者」 | 补全标点与「者」 |
| 缩略非原句 | 「势险节短」「得算多寡」系节缩 | 改为「其势险，其节短」「得算多也」「得算少也」 |
| 解释语误用引号 | 「管得动」「奇怪」「逐项相对比较」「专业判断与上级指令冲突」 | 改用『』或取消引号，明确不是原文 |

另有 3 条补了缺失锚点：Q-037 补九变篇第 1 段、Q-038 补谋攻篇第 8 段（「縻军」出处）、Q-056 补兵势篇第 4 段。

**引号用法约定**：「」只用于底本原文引文，可逐字回查；『』与“”用于解释性表述或异文（如银雀山汉简本），不代表本书文字。修订前的文件备份为 `qa.jsonl.bak`。

**未成卡的 37 段**主要是：作战篇的成本清单细节、虚实篇的若干论证过渡句、九地篇的将军事务描述、用间篇的开销账。它们价值在于论证过程而非可抽取的结论，保留在片段层即可。

## 五、怎么用

**做 RAG 知识库**：`segments.jsonl` 和 `knowledge.jsonl` 一起入库。检索命中片段后，用 `锚点` 回原文；命中知识卡则直接回答概念问题。两层混用效果最好——片段保证准确，卡片保证完整。

**做指令微调**：`qa.jsonl` 可以直接转成指令格式：

```json
{"messages":[
  {"role":"user","content":"孙子为什么说兵贵胜不贵久？"},
  {"role":"assistant","content":"三个层次的代价：钝兵挫锐、攻城力屈、国用不足……（答案引自 qa.jsonl）"}
]}
```

建议只微调「事实」「理解」两类（50 条），「应用」类含现代解读，容易带偏。

**做题库**：`knowledge.jsonl` 的 `要点` 字段天然是选择题的干扰项来源，`原文` 是简答题的标准答案，`易混淆` 是可考点。始计、谋攻、九地三篇最适合出题。

**做规则库/决策清单**：`rules.jsonl` 每条都是现成的 if-then，`边界` 就是例外条款。可直接落到业务 SOP 或决策辅助工具里。

**做导读/讲义**：`topics.jsonl` 是把这批资产变成可读物的唯一入口。一张卡把散在 2–4 篇的同一件事按阅读顺序叠好，适合做导读本、培训讲义、有声课脚本。同名的 HTML 页（`孙子兵法_主题聚合读法_样张.html`）是它的可视化版本。

**给编辑看**：`卡片看板.html` 支持搜索「诸葛亮」「授权」「成本」这类词，快速定位相关条目。

## 六、必须知道的局限

1. **`定义`、`延伸`、`原理` 是二次加工**，是我的解读，不是原文。对外引用时，只有 `原文` 字段可以直接当引文用，其余应标注「据某书某篇引申」。
2. **`延伸` 里的现代类比（商业、管理、并购）属当代应用**，与原书本意有距离。做严肃出版时建议删除或明确标注为「今用」。
3. **底本脱误未在卡片中改字**。涉及处已加 `校勘注`，如 K-016「守则不足，攻则有余」与汉简本相反、K-031「众争为危」通行本作「军争为危」。
4. **应用类问答（Q065–Q070）** 是我按商业场景写的迁移，不是孙子原话能直接支撑的结论。
5. 覆盖率 75%，若要全覆盖，剩下 37 段可补卡，但边际收益不高。
6. **主题卡的层次划分（定义→名单→通则→动作→原理）是整理者的编排**，不是孙子本人的分类；`结论` 字段同理。一张卡里能直接当引文的只有 `层[].句` 与 `对照.甲/乙`。
7. **「九变」的数目缺口照实写**：原文能数出五条处置加五条例外，篇内还自称「五利」，凑成九条要借九地篇。注家对此有不同解释，那属整理者说明，本节不作裁断。

## 七、如果要继续扩

这套流程可以复用到别的书：`原文 → segments（脚本自动切）→ 卡片（人工/模型抽取）→ 引文回查校验（脚本）→ 看板`。真正费工的是卡片写作与引文校验，切段可以全自动。

《孙子兵法》只有 6042 字，做到这个密度是可行的。换成十万字以上的书，就必须先做分层抽样——先抽目录与结论句，再决定哪些章节值得逐段成卡。
