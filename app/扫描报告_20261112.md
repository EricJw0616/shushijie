# 交互与截断扫描 · 2026-11-12

范围：15 个路由（工作台 / 图书库 / 知识资产 / 图书档案 / 全局检索 / 入库任务 /
书概览 B56,B58 / 知识资产页签 / 标签体系 / 原文 / 操作记录 / 应用中心 / 解析能力 / 回收站）

方法：真实渲染后读 DOM，查三类
- A 假按钮：有 onclick，但去掉 alert 后不做任何事
- B 假控件：长得像 chip/tag，或样式是手型，但自己与祖先都没有处理函数
- C 空按钮：button 无 onclick、无表单行为

## 结论

| 类型 | 位置 | 状态 |
|---|---|---|
| A 假按钮 | 应用中心：申请接入 / 接入说明 / 排期（3 个） | 明确不修（第二阶段功能，占位可接受） |
| A 假按钮 | 侧栏：数据源与 API、成员与权限（带 soon 标记） | 知情占位，可接受 |
| B 假控件 | 书概览「这本书怎么用」的科名 chip（原本无 onclick） | **已修**：改为按科精确筛选 |
| 静默截断 | 科名 16/118，无「更多」出口 | **已修**：前 10 + 全部 118 下拉 |
| 静默截断 | 可引用句 8/85，只有数字没有出口 | **已修**：head 加「查看全部 85 句 →」→ 原文页签「可引用句」视图 |
| 静默截断 | 按篇翻书 slice(0,40)，大书会截且无出口 | **已修**：>40 篇时出现「查看全部 N 篇 ›」→ 原文页签 |
| C 空按钮 | 无 | 回收站「恢复」在生效层已有 onclick；无 onclick 的那个在被覆盖的原型层 |

## 误报（不算问题）
- `pill` / `badge`：状态标签，不是控件，不应可点
- 侧栏 nav-item：事件是 addEventListener 委托绑定，扫描器已排除
