# 制作包 PDF：共用导出能力

图片、视频制作包统一使用此导出链路。版式与交付说明集中维护，不能按书名、项目编号、具体年龄或单个案例添加分支。

## 接入与职责

1. `project_assist.get_run_download`：检查访问范围、生成是否完成和版本是否过期，取得已保存记录。下载过程中再次检查版本，仍沿用现有旧版确认规则。
2. `production_document.build_production_document(run)`：把已保存内容整理为展示字段。只读取传入的记录及其当时的快照，不查当前项目、书库或生成服务。不认识的文档返回 `None`，沿用原文排版。
3. `manuscript_pdf.render_export_pdf(snapshot)`：统一处理中文字体、纸张、页边距、页眉页脚和文件输出。`export.content_kind = 'visual_production'` 且含有效 `production_document` 时调用专用版式；其他导出保持原入口。
4. `production_pdf.story(document, font, bold, width)`：只负责排列内容、分节、跨页和书签，不生成内容、不判断事实、不改写提示词。

新入口应调用这条链路或向公共排版入口传入同样的展示结构，不复制一份 PDF 模板。

## 展示结构

| 字段 | 用途 |
| --- | --- |
| `presentation_mode`、`title`、`topic` | 制作方式与项目主题 |
| `book_titles`、`audience`、`visual_style`、`aspect_ratio` | 已保存的图书名称、本次画面的观众、视觉风格与画幅 |
| `narration` | 完整口播，每项为 `number`、`text`；没有可靠段号时可不编号 |
| `shots` | 按顺序排列，包含 `number`、`title`、完整 `prompt`、口播映射，以及可选的后期文字和视频时长 |
| `references` | 实际列出的参考图名称、要求及对应画面编号 |
| `steps` | 制作人员要执行的简短步骤 |

空值不填占位内容；无参考图不显示参考图章节；缺完整口播不要求用户从本文件录制完整口播。不推测购买者，也不拿图书读者替换本次视频观众。

## 用户可见内容规则

- 先给口播，每张图或每个镜头另起一页；超长提示词允许续页，页眉保留所属画面编号。
- 提示词原文完整保留，受众、风格、比例、准确参考、动作时段和衔接都属于执行要求。不能为精简 PDF 而让同一条提示词与页面复制内容不同。
- 参考图只写具体要求及用于哪一画面，不把未接收的图像文件标成“已提供”，也不制造第二套“待确认”工作流。
- 交付说明只说明用户要做什么，不显示校验过程、内部状态、实现字段或重复的“本包尚未生成……”声明。
- 仅改写已知的系统模板说明。特殊制作步骤、定制正文和附注不能丢失；无法可靠识别时保留原文格式。
- 字体使用项目内置字体，不依赖 macOS、Windows 或本机字体安装。
- 中文正文与富文本共用行首禁则补充，避免问号等中文标点单独换行，并在正文栏内预留标点悬挂空间。
- 当前默认制作步骤由 `video_prompts.production_steps` 统一提供；投影同时识别明确的旧版系统步骤，未知自定义步骤仍完整保留。

## 下载命名

统一调用 `download_names.production_filename`，使用「项目名_图片制作包.pdf」或「项目名_视频制作包.pdf」。项目名取生成记录保存的名称，缺失时依次取当时的主题、图书名，最后用“未命名项目”。旧版仅增加“旧版-”前缀，不附加日期、版本号或内部编号。重复下载仍由浏览器加“(1)”等后缀。

`download_names.document_filename` 负责共用的跨平台字符清理和长度限制。服务端返回的 `download_filename` 与 HTTP 下载名采用同一规则，前端响应头缺失时使用该字段，避免退回不带项目名的通用文件名。

## 验收

核心回归文件：`tests/test_production_document.py`、`tests/test_production_pdf.py`、`tests/test_project_assist_pdf.py`、`tests/test_manuscript_pdf.py`。

至少覆盖不同题材与受众、图片/视频、无参考图、历史记录、定制附注、自定义制作步骤、超长中文跨页和下载期间版本变化。比较提示词与冻结口播全文，检查下载没有写入项目或生成记录，再把 PDF 渲染为图片检查乱码、裁切和分页。测试样本不能成为生产代码中的特例。
