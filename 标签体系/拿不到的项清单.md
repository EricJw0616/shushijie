# 拿不到的项清单（1/2/4 期范围）

> 口径：只针对本期要做的 59 项。分四种“拿不到”，处理方式完全不同。
> 总原则：**有就显示，没有就不显示；不适用就不显示；绝不让大模型补。**

## 一、只能人工/外部录入（本期 4 项）

| 项 | 为什么拿不到 | 系统怎么处理 |
|---|---|---|
| 权利状态 | 不在书里，是授权事实 | 人工/法务录入；没录入就不显示 |
| 权利归属方式 | 法人作品/职务作品等，要合同 | 同上 |
| 权利获取方式 | 许可/转让/自有，要合同 | 同上 |
| 使用许可范围 | 期限/被许可方/限制，要合同 | 同上；到期提醒 |

这 4 项大模型也解决不了。谁要说“AI 能判版权”，那是瞎说。

（“上市时间”本期不做，见第五节。）

## 二、书上有才有，没有就抽不到（10 项）

| 项 | 什么情况下没有 | 系统怎么处理 |
|---|---|---|
| 责任编辑 | 版权页没印、无版权页 | 不显示；可人工补 |
| 副书名 | 本书没有副书名，或主副标题混排 | 不硬拆；人确认 |
| 装帧形式 | 版权页/封底没写 | 不显示；不从封面照片猜 |
| 页数 | 版权页没印、套书只给总页数 | 不显示；不用 PDF 物理页数顶替 |
| 丛书名 | 不是丛书、没印 | 不显示 |
| 作者简介 | 封底/勒口没有现成简介 | 不显示；**不让 AI 写**（基础包只抽现成的） |
| 内容简介（基础包） | 书上没印简介 | 不显示；营销包的“整书概括”是另一条规则 |
| 作者 | 无版权页，封面也没有 | 不显示；可人工填/出版社元数据导入 |
| 出版社 | 无版权页，封面也没有 | 不显示；可人工填/导入 |
| 出版时间/版次/印次/字数/定价/CIP 号 | 无版权页（如部分图鉴、画册、文学书） | 整组不显示；有出版社元数据就导入 |

这一组不是技术失败，是**书上确实没有**。硬让模型写，就是编。

## 三、能抽，但抽不稳，必须人确认（9 项）

| 项 | 不稳在哪 | 系统怎么处理 |
|---|---|---|
| 翻译相关人员 | 外国人名、括号、多角色混在著者串 | 规则拆分 + 人确认 |
| 开本 | 只写“16 开”没尺寸，或尺寸和开数混排 | 拆两条；缺哪条不补哪条 |
| 书号 | 非 ISBN、10 位、统一书号格式杂 | 只认能校验的；其他人工 |
| 分类信息 | 只有代码没名称、多体系、无版本 | 只存书上有的；不猜体系 |
| 目录 | 目录块≠目录页；目录可能跨多页 | 识别页码区间；人可拖拽调整 |
| 索引 | 样本少，和“专名索引”产物容易混 | 识别不到标“其他”，不硬标 |
| 勘误表 | 极少见 | 同上 |
| 标题层级 | 第 3 期不做字号，只能靠编号/缩进 | 部分支持；不承诺全准 |
| 营销 6 项 | 目标读者/情绪价值是主观判断 | AI 出草稿 + 人采纳；不承诺“自动正确” |

## 四、格式不支持（3 类）

| 情况 | 影响 | 系统怎么处理 |
|---|---|---|
| DOCX/TXT | 没有“页”，页级结构（封面/版权页/目录…）无法按页判断 | 只按标题/文本顺序判断；页级项标“不适用”，不导出 |
| 扫描版 PDF（无文字层） | 文字抽不出，出版信息和页面结构都做不了 | 明确拒绝或转人工；不做“假装读到了” |
| 图鉴/画册类 | 常没有标准版权页，版面也不是常规图文 | 出版信息可能整组缺；页面角色按图鉴规则单独调 |

## 五、本期不做，所以也没有（46 项）

| 内容 | 项数 |
|---|---|
| 图文/图表（插图、表格、公式、图注、图表与工程内容等） | 17 |
| 文字样式（粗体、字号、颜色、对齐、段落等） | 17 |
| 理解类（概念、原理、事实数值、词性句法、指代、知识关系） | 11 |
| 上市时间 | 1 |

## 六、显示规则（按你的要求）

1. **有值才显示**：界面和导出只出现“已确认/自动采用”的值。
2. **没有就不显示**：不出现“未找到”“暂无”占位，不瞎标。
3. **不适用也不显示**：比如小说没有索引，不算缺项。
4. **内部仍记状态**：未找到/不适用/待人工只进质量报告，用来算覆盖率和排期，不进入交付字段。
5. **永不补写**：大模型只能给“候选 + 原文证据”；没有证据就不落，绝不生成。
6. **可配置**：如果客户合同要求显式 null，导出时加开关，按客户模板来。

## 七、大模型到底能帮到哪一步

| 能帮 | 不能帮 |
|---|---|
| 从大段文字里找候选（副书名、作者简介、译者、丛书） | 判断版权归谁、许可范围 |
| 页面角色拿不准时做兜底判断 | 书上没有的页数/装帧/责任编导出“答案” |
| 分类给候选（最终要人确认） | 保证多角色拆分一定对 |
| 营销 6 项出草稿 | 保证“目标读者/情绪价值”客观正确 |
| 把长简介压缩成短简介（带原文） | 替代法务/业务的事实录入 |

底线：**大模型是“找候选 + 写草稿”，不是“造事实”。**
