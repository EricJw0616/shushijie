# 实体分类：通用化修复报告

> 2026-11-17｜目标：不再按单本书打补丁；所有书共用一套分类器。

## 一、现在的结构

```
实体抽取（模型只出候选）
        ↓
entity_classify.py（唯一分类入口）
  ├─ 地理词典：国家/省/区域/市/区县/地标/自然
  ├─ 词形规则：机构/奖项/事件/朝代/器物/概念
  ├─ 上下文：说/著/位于/公司/奖/战争/别名
  └─ 拿不准 → other，进人工
        ↓
entities.jsonl / store.get_entities / 审核页
```

- 分类器只有一份：`platform/engine/entity_classify.py`；
- 抽取、页面、批量重洗都调用它；
- 单本例外只写 `entity_review.json`，不写全局词典；
- 已停掉“模型结果自动进词典”的旧逻辑。

## 二、回归结果

同一批 99 条随机样本，盲评复核：

| 版本 | 一致率 |
|---|---|
| 第一轮规则 | 83.8% |
| 通用分类器 | **92.9%** |

剩下 7 条不一致里，人工复核：

- 盲评错 5 条：物理科（机构）、内蒙古自治区（省份）、江村/序水村（区县）、衡山（自然地理）；
- 真正存疑 2 条：柳毛子（别名/植物）、京杭大运河（自然/地标）。

## 三、这轮修掉的通用问题

| 问题 | 修法 |
|---|---|
| 上海被“海”判成自然地理 | 行政区词典优先 |
| 中国被“说”判成人物 | 地理词典先于上下文 |
| 保卫科/物理科/水下考古部门被判“科/门” | 科室后缀与分类阶元分开 |
| 通榆/富阳/七台河/河北邢台 | 短名补后缀查行政区词典 |
| 戒石坊/拉福火车站 | 站/坊/牌坊归地标 |
| 腊鸭 | 食品归器物 |
| 五代 | 朝代词表 |
| 满族人 | 民族归概念 |
| 江村/序水村 | 村后缀归区县 |
| 同名多类 | 同名按票数+优先级只留一个类别 |

## 四、仍然解决不了的

- 同形词必须靠上下文：衡山（山/饭店）、天国（概念/地名）、黄门（官署/门）、石生（人名/别名）；
- 这类现在会落到 `other` 或按上下文判，拿不准不硬塞；
- 不针对某一本书加规则。

## 五、复用方式

```python
from entity_classify import classify
cat, confidence, reason = classify(name, context, hint=model_cat)
```

- 新书上传：`entities.py` 自动调用；
- 页面读取：`store.get_entities` 自动调用；
- 历史数据重洗：`reclass_entities.py` 调用；
- 单本修正：只写该书的 `entity_review.json`。

## 六、下一步

2. 目标：地理类 ≥95%，机构/人物/概念 ≥90%；
3. 达不到就继续改分类器，不靠单本补丁。
