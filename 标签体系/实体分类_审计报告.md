# 实体分类审计报告（第一轮）

> 2026-11-17｜7 本书｜99 条随机样本｜“盲评”指第二次标注不看现有类别

## 一、方法

- 每本书每个类别随机抽 1 条，共 99 条；
- 用另一个提示词做“盲评”，只看名称+上下文；
- 人工复核两边不一致的 16 条，判断谁对谁错；
- 这是第一轮，不是最终金标准。

## 二、结果

| 指标 | 结果 |
|---|---|
| 机器 vs 盲评一致 | 83/99 = **83.8%** |
| 复核后：机器错 | 9 条 |
| 复核后：盲评错 | 6 条 |
| 估算机器准确率 | **90/99 ≈ 91%** |

## 三、确认的机器错误

| 书 | 名称 | 现在 | 应为 | 原因 |
|---|---|---|---|---|
| B56 | 东北药用植物 | org | concept | 书名式短语，不是机构 |
| B56 | 满族人 | person | concept | 民族不是具体人物 |
| B60 | 戒石坊 | object | landmark | “坊”是地标，不是器物 |
| B60 | 腊鸭 | animal | object | 食品，不是动物 |
| B60 | 黄门 | landmark | concept | 官署/门第概念，不是地点 |
| B60 | 五代 | concept | dynasty | 朝代 |
| B66 | 神兽之间 | object | concept | 抽象说法，不是器物 |
| YC | 天国 | landmark | concept | 宗教概念，不是地点 |
| B60 | 石生 | alias | person | 人名/字号，不是别名 |

## 四、盲评自己也错的（不能拿它当标准）

- 物理科：应为机构，盲评判概念；
- 内蒙古自治区：应为省份，盲评判区域；
- 江村、序水村：应为区县，盲评判区域；
- 衡山：应为自然地理，盲评判地标。

## 五、这轮改的通用规则

1. 短名查行政区词典：通榆→通榆县、富阳→富阳区、七台河→七台河市；
2. 分类阶元只对动植物生效，`保卫科/物理科/水下考古部门` 不再被当“科/门”；
3. `站/坊/牌坊` 归道路地标，`拉福火车站/戒石坊` 不再当器物；
4. 朝代词表：`五代` 归朝代；
5. 民族词：`满族人` 归概念，不归人物。

## 六、结论

- 当前不是“全对”，大约九成；剩下的是同形词和语境问题：
  - 衡山：山 vs 饭店；
  - 天国：宗教概念 vs 地名；
  - 石生：人名 vs 别名；
  - 黄门：官署 vs 地点。
- 这些问题不能靠再加几个后缀解决，要靠上下文或人工；
- **不再按单本书改全局规则**：单本例外只写 `entity_review.json`。

## 七、下一步

1. 每个大类随机抽 50 条，人工定标准，扩到 300–500 条；
2. 先修错误率最高的 3 类，不逐个名字打补丁；
3. 每改一次规则，重跑同一套样本，准确率不下降才上线。
